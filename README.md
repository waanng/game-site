## 游戏列表

### 🧱 Breakout - 打砖块
经典打砖块游戏，使用键盘左右箭头控制挡板，空格键发射球。

- **技术**: HTML5 Canvas + JavaScript
- **操作**: ← → 移动，空格发射
- **链接**: https://game.waanng.cn/games/breakout/

### ✈️ Plane Strike - 士字飞机大战
原创飞机大战游戏，士字形飞机设计，击中机头即摧毁。

- **技术**: HTML5 Canvas + JavaScript
- **操作**: 鼠标/触摸控制
- **链接**: https://game.waanng.cn/games/plane-strike/

### 🔮 Fractal Explorer - 分形探索器
探索数学之美，无限缩放曼德勃罗集和朱利亚集分形图案。

- **技术**: HTML5 Canvas + JavaScript
- **操作**: 鼠标拖拽移动，滚轮缩放，点击查看详情
- **链接**: https://game.waanng.cn/games/fractal-explorer/

## 技术栈

- HTML5 Canvas
- Vanilla JavaScript
- CSS3
- GitHub Pages 部署
